            #-Requirements-#
Before running MyMuApp, make sure you have:
1. Node.js
2. npm
3. yt-dlp
   
Check your installation:
node --version
npm --version
yt-dlp --version

             #-Installation-#
Clone the repository:
git clone https://github.com/imcasper019/MyMuApp.git

Enter the project directory:
cd MyMuApp

Install the Node.js dependencies:
npm install
npm start

           #-Run-#
node server.js

lalu buka browser
localhost:3001
